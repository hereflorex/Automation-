# FLOREXIA v4 — NOIR//NULL Content Agent

Florexia is a content-studio agent with a web dashboard plus remote control through Telegram and email notifications.

## Remote control
Telegram commands:
- `/start`
- `/status`
- `/plan`
- `/run` — runs the next queued job
- `/run JOB_ID`
- `/report`
- `/report JOB_ID`
- `/approve JOB_ID`
- `/publish JOB_ID`
- `/stats`

Telegram is the interactive control channel. Email is notification/report delivery.

### Telegram setup
1. In Telegram, open **@BotFather**.
2. Create a bot with `/newbot`.
3. Copy the bot token into `TELEGRAM_BOT_TOKEN`.
4. Message your bot once.
5. Get your numeric chat ID (use a trusted Telegram chat-ID method; never post it publicly).
6. Put it in `TELEGRAM_CHAT_ID`.
7. Deploy Florexia on Railway.
8. Set Telegram webhook:
   `https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://YOUR-RAILWAY-DOMAIN/telegram/webhook`
   Use a browser/curl, but never commit the token.
9. Send `/start` to the bot.

The webhook endpoint only accepts the configured TELEGRAM_CHAT_ID. Keep the bot token secret.

## Email setup
Email is outbound notification only. For Gmail SMTP, create a Google App Password and use it as SMTP_PASSWORD; do NOT use your normal Google password.
Set:
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=youraddress@gmail.com
SMTP_PASSWORD=your-app-password
REPORT_EMAIL_TO=youraddress@gmail.com

For another mail provider, use its SMTP host/port and credentials.

## Safety
Publishing stays approval-gated by default. `/publish` uploads as private in this build. Change publishing behavior only after you have tested the workflow.
Instagram remains OFF until you deliberately configure it later.

## Deployment
Railway is recommended for always-on scheduling and Telegram webhooks. Termux works for testing but Android may stop background processes.


## v5 creative upgrade
Florexia generates a stable NOIR//NULL channel banner plus topic-aware thumbnails. The brand identity stays consistent while thumbnail composition varies by topic. Titles, descriptions and tags are generated by the Story Agent. TTS voice is configurable via `OPENAI_TTS_VOICE`.

The creative renderer uses Pillow and works without an additional image API. Replace `app/creative.py` later if you want a separate image-generation provider.

Self-healing is bounded: known production failures retry; external outages, expired OAuth and missing dependencies are reported rather than hidden.
